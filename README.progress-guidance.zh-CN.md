# PageCraft 任务进度与智能评注指南

本文介绍 PageCraft 0.4.0 新增的两项交互能力：**真实任务进度时间线**和**智能修改引导**。它们分别解决“发送后不知道 Agent 在做什么”和“选中以后不知道怎样描述修改”两个问题。

## 1. 真实任务进度时间线

发送评注后，右侧会立即出现当前批次卡片，显示：

- 批次短 ID、评注数量、当前断点和累计耗时；
- 准备上下文、进入队列、定位源码、执行修改、验证结果、完成同步等阶段；
- DSH 当前可观察到的实际动作，例如读取文件、创建检查点、应用补丁或执行构建；
- 前方真实排队任务数；
- 完成后的视觉结论：检测到变化、未检测到变化或无法验证。

PageCraft **不会显示虚假的百分比、进度条或剩余时间**。无法可靠识别工具行为时，只显示“Agent 正在处理”。时间线可以收起，任务超过 60 秒后会明确说明可以关闭 PageCraft 继续工作；重新打开时，会根据本地批次历史和 DSH 会话状态恢复跟踪。

### 阶段含义

| 页面显示 | 代表什么 |
| --- | --- |
| 准备上下文 | 捕获修改前截图、整理评注与响应式上下文 |
| 进入队列 | 工单已交给 DSH，等待前置任务 |
| 定位源码 | Agent 正在搜索、读取并交叉核对 DOM 与源码 |
| 执行修改 | Agent 正在写文件或应用补丁 |
| 验证结果 | Agent 正在构建、测试、截图或检查结果 |
| 完成同步 | PageCraft 刷新页面并保存修改后快照 |

### 如何判断是否真正改动

- **已检测到视觉变化**：修改前后截图不同，可进入“比较与历史”拖动查看。
- **未检测到视觉变化**：截图完全相同。可能是非视觉修改、浏览器缓存、错误目标文件或 Agent 没有落盘，应刷新后复查。
- **视觉结果未验证**：截图缺失或预览无法加载。任务可能已完成，但 PageCraft 不会把它误报为已通过视觉验证。

## 2. 智能修改引导

点击“选择元素”或“框选区域”后，右侧不再只有空白输入框，而会先展示目标摘要和四类建议。点击任一建议会生成一份带当前目标、断点和响应范围的草稿；草稿不会自动进入队列或发送，可以继续编辑。

PageCraft 会按目标类型调整建议：

- 按钮、链接和导航：修改文案、突出主操作、调整尺寸位置、增加交互；
- 标题和正文：重写内容、优化排版、处理长文本、展开阅读；
- 输入框和表单：完善提示、统一样式、优化布局、增加校验反馈；
- 容器、卡片和表格：调整层级、优化视觉、重新布局、增加折叠或筛选；
- 图片、视频和图标：替换素材、优化呈现、调整比例、增加查看交互；
- 框选区域：新增内容、增加装饰、重新布局、加入交互模块。

### 推荐描述结构

一条高质量要求通常包含五部分：

1. **目标结果**：最终希望用户看到什么；
2. **内容**：新文案、素材或数据；
3. **视觉与布局**：层级、颜色、间距、位置和响应式行为；
4. **交互**：点击、加载、成功、失败和动效；
5. **不可改变项**：业务逻辑、字段名、数据格式或其他断点。

例如：

> 将“保存”按钮文案改为“保存配置”，调整为更明确的主操作样式，保留现有点击逻辑和字段提交格式；仅作用于当前 Mobile（390×844）断点，文字不得溢出，完成后进行视觉验证。

### 常用约束

编辑器下方提供“保留现有业务逻辑”“不改变数据格式”“不影响其他断点”“保持现有设计语言”“完成后进行视觉验证”等约束。点击只会追加尚未存在的约束，不会覆盖你的文字。

### 区域修改方式

- **插入**：新内容加入正常文档流，并推开后续内容；适合新增卡片、说明和表单区。
- **覆盖**：新内容浮在现有页面上方；适合浮层、标记和临时提示。
- **替换**：移除或重构选区覆盖的现有内容；适合整块升级，不适合仅添加装饰。

## 3. 推荐测试流程

1. 打开一个本地前端地址并选择 Mobile。
2. 选择一个按钮，点击“修改文案”，把占位文字改成真实目标后加入队列。
3. 框选一块空白区域，选择“新增内容”和“插入”，完善模块要求后加入队列。
4. 点击“发送给 Agent”，观察时间线是否从准备、排队进入定位、修改和验证。
5. 完成后打开“比较与历史”，确认视觉结论与前后截图一致。
6. 对某一批次执行安全恢复，确认文件哈希冲突时不会覆盖后续修改。

## 4. 边界与限制

- 具体工具名称取决于 DSH 会话快照。PageCraft 只根据可观察证据分类，不读取或展示模型隐藏推理。
- 如果 DSH 版本只暴露 `running`，时间线仍可显示排队、运行、同步和结果，但无法细分每个工具动作。
- 截图内容相同只能证明当前 URL 和视口没有可见像素变化，不能证明源文件完全没有变化。
- PageCraft 只生成并发送工单；源码修改仍由 Agent 在当前工作区执行。
